## Make my Web Screen Recorder 2.4.2

### Fixed
- **Clearer microphone sound.** The microphone is now recorded through the same Windows audio system as the computer's sound, which fixes crackling, clicks and little gaps in your voice on many PCs.

### Install
Download `MakeMyWebScreenRecorder-Setup-2.4.2.exe` below and run it (no admin rights needed). Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**.

Already on 2.2.0 or later? You'll be offered this update when you open the app.
