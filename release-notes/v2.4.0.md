## Make my Web Screen Recorder 2.4.0

### New
- **Camera effects:** turn on *Camera* and click **Effects** for a live preview with **background blur**, five built-in **scenes** or **your own picture**, and **colour filters** (warm, cool, black & white, bright). Effects run on your PC; the small background model (under 1 MB) is downloaded the first time you choose a background effect.
- **Your choice on update checks:** the app now asks once before checking GitHub for updates. You can change it any time in ⚙ Settings.

### Changed
- **Subtitles have been removed** to keep the app simple. Speech models downloaded by version 2.3 are deleted automatically, freeing up to about 700 MB.

### Install
Download `MakeMyWebScreenRecorder-Setup-2.4.0.exe` below and run it (no admin rights needed). Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**.

Already on 2.2.0 or 2.3.0? You'll be offered this update when you open the app.
